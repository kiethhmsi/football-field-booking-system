# Screenshots & Demos

Thư mục này dùng để lưu trữ các hình ảnh chụp màn hình (screenshots) demo các chức năng chính của dự án KaSport, giúp tài liệu README sinh động và chuyên nghiệp hơn.

## Danh sách hình ảnh đề xuất:
- `admin_dashboard.png`: Giao diện tổng quan trang quản trị kèm biểu đồ doanh thu.
- `booking_view.png`: Giao diện đặt sân bóng đá động theo thời gian thực.
- `matchmaking.png`: Giao diện tìm kèo đấu, đối thủ phong trào.
- `ai_chatbot.png`: Giao diện chatbox với trợ lý AI thông minh.
- `payment_qr.png`: Giao diện màn hình quét mã QR thanh toán PayOS.
